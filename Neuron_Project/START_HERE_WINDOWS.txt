│ SPECIAL NOTES                                                                │
└──────────────────────────────────────────────────────────────────────────────┘

  Intel Integrated Graphics Users:
  The application will automatically enable "Safe Mode" for stability.
  This is normal and ensures smooth operation on Intel GPUs.
  
  Laptop Users with Dual GPUs:
  If performance is slow, make sure Windows is using your dedicated GPU:
  Settings → System → Display → Graphics settings
  → Add python.exe → Set to "High performance"

┌──────────────────────────────────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────────────────┘

  Left Mouse Button:    Rotate 3D view
  Middle Mouse Button:  Pan view
  Scroll Wheel:         Zoom in/out
  
  Open Figure → Select Path → Choose TIFF file → Open
  Select colors → Click Next → Process each neuron segment
  Target Folder → Select where to save results
  Click Save on each color tab to export data
