┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING DEBUG MODE                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

Problem: "No module named 'matplotlib_config'"
Fix: Ensure venv Python is selected in VS Code
     Bottom left corner → Click Python version → Select venv\Scripts\python.exe

Problem: Still getting matplotlib Qt errors
Fix: Reload VS Code window
     Ctrl+Shift+P → "Reload Window"

Problem: Breakpoints are gray/hollow (not working)
Fix: 1. Stop debugging (Shift+F5)
     2. Delete __pycache__ folders
     3. Restart VS Code
     4. Try again

Problem: Nothing happens when pressing F5
Fix: 1. Check .vscode/launch.json exists
     2. Check Python interpreter is set (venv)
     3. Try "Run → Start Debugging" from menu

Problem: "Debugger is attached" but frozen
Fix: 1. Stop all Python processes
     2. Close VS Code
     3. Open Task Manager → End python.exe tasks
     4. Restart VS Code
